## English

### Introduction

**SUBQUICK** is a Windows desktop application for searching and downloading movie subtitles from **SubSource** and **SubDL**. This repository provides official installer releases for end users.

### Features

| Feature | Description |
| --- | --- |
| Flexible search | Search by movie file, title, or IMDb ID. |
| Movie and TV support | Support movies, TV series, and season selection. |
| Multiple providers | Search subtitles from SubSource or SubDL. |
| Quick filtering | Filter subtitle results by name, episode, release, or keyword. |
| Detailed information | View upload date, download count, type, source, and Hearing Impaired status. |
| Flexible downloads | Download one subtitle or multiple files from a package. |
| Common formats | Support `.srt`, `.ass`, `.ssa`, `.vtt`, and `.sub` subtitle files. |
| Bilingual interface | Use the application in English or Vietnamese. |

### Installation

1. Download the latest `SUBQUICK_Setup_1.0.0.exe` file from the **Releases** page.

1. Run the Setup file and select **Install**.

1. Follow the instructions on the screen.

1. Launch SUBQUICK from the Desktop shortcut or the Start Menu.

The Setup package includes the required components. No additional installation is required.

### How to Use

1. **Configure a provider:** Select **SubSource** or **SubDL**, enter the API Key for the selected provider, and click **Save API Key**. Both API Keys can be entered and saved; the selected provider must have a valid key to perform a search.

1. **Choose a search method:** Select a movie file or enter a movie title/IMDb ID.

1. **Select a movie:** Choose a movie from the results. For a TV series, select the required season.

1. **Select a subtitle:** Choose a subtitle result. Use the filter box to search for a keyword such as `e04`.

1. **Download:** Click **Download selected subtitle** and follow the instructions shown on screen.

## Tiếng Việt

### Giới thiệu

**SUBQUICK** là phần mềm desktop dành cho Windows, giúp tìm kiếm và tải phụ đề phim từ **SubSource** và **SubDL**. Repository này cung cấp các bản cài đặt chính thức dành cho người dùng cuối.

### Tính năng

| Tính năng | Mô tả |
| --- | --- |
| Tìm kiếm linh hoạt | Tìm theo file phim, tên phim hoặc IMDb ID. |
| Hỗ trợ phim lẻ và phim bộ | Hỗ trợ chọn phim, phim bộ và mùa phim. |
| Nhiều nguồn phụ đề | Tìm kiếm từ SubSource hoặc SubDL. |
| Lọc nhanh | Lọc kết quả theo tên, tập phim, release hoặc từ khóa. |
| Thông tin chi tiết | Hiển thị ngày đăng, lượt tải, loại, nguồn và trạng thái Hearing Impaired. |
| Tải linh hoạt | Tải một phụ đề hoặc nhiều file trong package. |
| Định dạng phổ biến | Hỗ trợ phụ đề `.srt`, `.ass`, `.ssa`, `.vtt` và `.sub`. |
| Giao diện song ngữ | Sử dụng giao diện tiếng Việt hoặc tiếng Anh. |

### Hướng dẫn cài đặt

1. Tải file `SUBQUICK_Setup_1.0.0.exe` mới nhất từ trang **Releases**.

1. Chạy file Setup và chọn **Install**.

1. Làm theo hướng dẫn trên màn hình.

1. Mở SUBQUICK từ shortcut trên Desktop hoặc Start Menu.

Bản Setup đã có sẵn các thành phần cần thiết. Người dùng không cần cài đặt thêm.

### Hướng dẫn sử dụng

1. **Cấu hình nguồn:** Chọn **SubSource** hoặc **SubDL**, nhập API Key của nguồn được chọn rồi nhấn **Lưu API Key**. Có thể nhập và lưu cả hai API Key; nguồn được chọn phải có API Key hợp lệ để tìm kiếm.

1. **Chọn cách tìm:** Chọn file phim trên máy tính hoặc nhập tên phim/IMDb ID.

1. **Chọn phim:** Chọn phim trong danh sách kết quả. Với phim bộ, chọn đúng mùa phim.

1. **Chọn phụ đề:** Chọn bản phụ đề cần tải. Có thể nhập từ khóa như `e04` vào ô lọc để tìm nhanh.

1. **Tải xuống:** Nhấn **Tải phụ đề đã chọn** và làm theo hướng dẫn trên màn hình.
