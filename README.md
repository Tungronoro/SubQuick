## English

### Introduction

SUBQUICK is an application for searching and downloading movie subtitles from **SubSource** and **SubDL**. This release is distributed to end users as an installer; the source code is not included in the public release package.

### Features

- Search subtitles by movie file, movie title, or IMDb ID.
- Support movies, TV series, and season selection.
- Search from SubSource or SubDL.
- Quickly filter subtitle results by name, episode, or keyword.
- Display subtitle name, upload date, download count, type, source, and Hearing Impaired status.
- Download one subtitle or multiple files from a package.
- Support common subtitle formats such as `.srt`, `.ass`, `.ssa`, `.vtt`, and `.sub`.
- Support Vietnamese and English user interfaces.

### Installation

1. Run `SUBQUICK_Setup_1.0.0.exe`.
2. Select **Install** and follow the instructions on the screen.
3. After installation, launch SUBQUICK from the Desktop shortcut or the Start Menu.

The Setup package already includes the required components. Users do not need to install Python or additional libraries separately.

### How to Use

1. **Step 1 – Configuration:** Select one subtitle source, **SubSource** or **SubDL**, enter the API Key, and click **Save API Key**.
2. **Step 2 – Choose a search method:** Select a movie file or enter a movie title/IMDb ID.
3. **Step 3 – Select a movie:** Choose a movie from the results. For TV series, select the required season.
4. **Step 4 – Select a subtitle:** Choose the subtitle to download. You can enter a keyword such as `e04` in the search box to filter episode 4 subtitles.
5. Click **Download selected subtitle** and follow the download instructions shown on screen.

## Tiếng Việt

### Giới thiệu

SUBQUICK là phần mềm tìm kiếm và tải phụ đề phim từ **SubSource** và **SubDL**. Phiên bản phát hành dành cho người dùng cuối dưới dạng bộ cài đặt; mã nguồn không được đưa vào gói phát hành công khai.

### Tính năng

- Tìm phụ đề theo file phim hoặc theo tên phim/IMDb ID.
- Hỗ trợ phim lẻ, phim bộ và chọn mùa phim.
- Tìm kiếm từ SubSource hoặc SubDL.
- Lọc nhanh danh sách phụ đề theo tên, tập phim hoặc từ khóa.
- Hiển thị tên bản phụ đề, ngày đăng, lượt tải, loại, nguồn và trạng thái Hearing Impaired.
- Hỗ trợ tải một phụ đề hoặc nhiều phụ đề trong package.
- Hỗ trợ các định dạng phụ đề phổ biến như `.srt`, `.ass`, `.ssa`, `.vtt` và `.sub`.
- Hỗ trợ giao diện tiếng Việt và tiếng Anh.

### Hướng dẫn cài đặt

1. Chạy file `SUBQUICK_Setup_1.0.0.exe`.
2. Chọn **Install** và làm theo hướng dẫn trên màn hình.
3. Sau khi cài xong, mở SUBQUICK từ shortcut trên Desktop hoặc Start Menu.

Bản Setup đã đóng gói sẵn các thành phần cần thiết. Người dùng không cần cài Python hoặc các thư viện phụ trợ riêng.

### Hướng dẫn sử dụng

1. **Bước 1 – Cấu hình:** Chọn một nguồn phụ đề là **SubSource** hoặc **SubDL**, nhập API Key rồi nhấn **Lưu API Key**.
2. **Bước 2 – Chọn cách tìm:** Chọn file phim trên máy tính hoặc nhập tên phim/IMDb ID.
3. **Bước 3 – Chọn phim:** Chọn phim trong danh sách kết quả. Với phim bộ, chọn đúng mùa phim.
4. **Bước 4 – Chọn phụ đề:** Chọn bản phụ đề cần tải. Có thể nhập từ khóa như `e04` vào ô tìm kiếm để lọc nhanh các bản phụ đề của tập 4.
5. Nhấn **Tải phụ đề đã chọn** và chọn tùy chọn tải theo hướng dẫn trên màn hình.
